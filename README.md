# Blair Page Portfolio Card

A responsive personal portfolio card showcasing professional experience, education, certifications, and social links through a modern HTML, CSS, and JavaScript interface.

## Features

- Responsive desktop and mobile design
- Professional portfolio presentation
- Light and dark mode support
- Interactive profile card layout
- AWS, Linux, Cloud, and Business credentials
- Education and certification highlights
- Social media and contact links
- GitHub Pages ready
- Fast-loading static website
- Pure HTML, CSS, and JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
